# Animal Farm v1.0.0

First public release. A tiny pixel farm that floats on your desktop.

## Download

**AnimalFarm_Windows.zip** (30 MB) — Windows 10 / 11, 64-bit

SHA-256:

```
53ca6c90ac2ef29961d6bb7c5a355d1006148a1a313cc48a350b7d1511c44bc0
```

## What's in it

- A frameless, always-on-top, transparent farm that sits over your desktop
- Chickens and cows that wander, idle and lay eggs on their own
- Click eggs to collect coins, spend them in the shop on chicks, hens and calves
- Drag the farm anywhere; shrink it to a corner; hide the UI
- Auto-save every 30 seconds

## Install

1. Download `AnimalFarm_Windows.zip`
2. Unzip anywhere (do not run from inside the zip)
3. Run `AnimalFarm.exe`
4. If SmartScreen warns: **More info → Run anyway** (the build is not code-signed)

## Controls

| Action | Input |
|---|---|
| Move the farm | drag the grass with the left mouse button |
| Collect an egg | click it (+100 coins) |
| Shop | basket icon — hen 100, chick 50 |
| Shrink / restore | minus icon |
| Hide UI | eye icon |
| Quit | exit icon → Yes |

## Known issues

- The farm is drawn in the bottom-right corner of the screen at 1080p and can end up partially behind the taskbar. Drag it to a better spot.
- The build is unsigned, so Windows SmartScreen and some antivirus engines warn on first run.
- Windows only. The transparent always-on-top window is Win32-specific, so there is no macOS or Linux build.
